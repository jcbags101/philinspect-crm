# CRM Core

A first-party App Factory template for isolated client CRM deployments.

## Included

- Next.js App Router
- Neon-compatible PostgreSQL migrations
- Organization-scoped CRM schema
- Permission-based RBAC foundation
- Contacts, companies, leads, pipeline, deals, tasks, activities, and audit logs
- Configuration-driven modules and branding foundation
- Health endpoint for automated provisioning verification

## Local setup

Copy `.env.example` to `.env.local`, set `DATABASE_URL`, then run `npm install` and `npm run dev`.

This repository is managed by App Factory. Template version: 0.1.0.
